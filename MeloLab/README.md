# Melo Lab · Руслан

Исходный Android-проект для музыкальных идей под trap, drill и другие направления хип-хопа: тональности, аккорды, мелодии, прослушивание и MIDI для FL Studio. Интерфейс на русском, в тёмных фиолетовых цветах. Проекты сохраняются на телефоне.

## Получить APK

1. Распакуй ZIP на компьютере и открой папку **MeloLab** в **Android Studio**. В ней находится `settings.gradle`.
2. Выбери **JDK 17 или JDK 21** в **Settings → Build, Execution, Deployment → Build Tools → Gradle → Gradle JDK**.
3. Дождись синхронизации. **Для первой сборки нужен интернет на компьютере**, чтобы загрузить Gradle, плагин Android и SDK.
4. Через SDK Manager при необходимости установи **Android SDK Platform 35** и **Build-Tools 35.0.0**.
5. Выбери **Build → Build App Bundle(s) / APK(s) → Build APK(s)**. Название пункта зависит от версии Studio.
6. Файл для установки: **`app/build/outputs/apk/debug/app-debug.apk`**. Передай его на телефон и открой; разреши установку из приложения, через которое открываешь APK.

Нужен **Android 8.0 или новее**. Debug APK подходит для личной установки и автоматически получает тестовую подпись. **Готового APK в архиве нет: полная Android-сборка и запуск на телефоне здесь не выполнялись.**

## Что можно делать

- Выбирать жанр, темп, тонику и лад; видеть ноты тональности и их расположение на клавиатуре.
- Собрать аккордовую последовательность, изменить аккорды, длительность и обращение; прослушать звучание.
- Создать мелодию алгоритмом, сделать её реже или плотнее, изменить ноты на сетке и отменить генерацию.
- Слушать аккорды, мелодию и бас вместе или включать нужные партии отдельно.
- Использовать справочник ладов и аккордов, конструктор и распознавание аккорда по выбранным нотам.
- Сохранять отдельные проекты, делать копии, экспортировать MIDI и резервную копию JSON через системный выбор файла.

В приложении есть явно обозначенная стартовая идея. Генератор мелодии работает по музыкальным правилам с повторяемым seed; нейросеть и сервер для генерации не используются. Прослушивание использует простые синтезированные тембры. Свои пианино, синты и 808 назначай уже в FL Studio. При выходе из приложения или блокировке экрана звук останавливается.

## MIDI для FL Studio

На вкладке **«Идея»** нажми **«Экспорт MIDI для FL Studio»**, сохрани `.mid`, перенеси файл на компьютер и открой его через **File → Import → MIDI file** в FL Studio либо перетащи в FL Studio. Выбери нужные дорожки и назначь им инструменты.

MIDI содержит отдельные партии **аккордов, мелодии и баса**, темп и размер 4/4. Переключатели прослушивания не удаляют партии из экспорта: экспортируются все три. В приложении принята нумерация октав FL Studio: **MIDI 60 = C5**. Энгармонические названия вроде G# и Ab обозначают одну высоту.

Можно сразу проверить стартовую идею: [MIDI для FL Studio](docs/starter-idea.mid) и [звуковой пример WAV](docs/starter-idea.wav). Оба файла получены из настоящей музыкальной логики проекта: F minor, 140 BPM, около 7 секунд. WAV записан синтезатором проекта на компьютере; это пример тембров, а не запись воспроизведения на телефоне.

## Google AI Mode

На вкладке **Google** отредактируй вопрос и при желании включи контекст текущего проекта: жанр, темп, тональность и аккорды. Явная кнопка копирует вопрос и открывает Google в браузере. Интернет использует браузер; само приложение не запрашивает доступ в интернет.

Ответ остаётся в Google. Приложение не читает страницу, не загружает ответ и не превращает его автоматически в MIDI. Доступность AI Mode зависит от Google, аккаунта и региона; переход с параметром AI Mode может открыть обычный поиск. API-ключи и аккаунт внутри Melo Lab не нужны.

## Данные и сборка

Перед переустановкой или переносом на другой телефон экспортируй резервную копию. Удаление приложения удаляет локальные проекты; облачной синхронизации нет. Импорт проверяет JSON и предлагает заменить данные только после подтверждения.

Иллюстрация интерфейса: [docs/interface-preview.png](docs/interface-preview.png). Длинные экраны с прокруткой сокращены, чтобы показать основные элементы вместе; это не снимок с телефона.

Подробные команды и список проверки устройства: [docs/BUILD.md](docs/BUILD.md); выполненные проверки — [docs/VERIFICATION.md](docs/VERIFICATION.md). В архив включён небольшой собственный `gradle-wrapper.jar` с исходником; это **не официальный бинарный Gradle wrapper**. Он скачивает официальный Gradle 8.9 и запускает его.
