# Проверка исходников Melo Lab

Все перечисленные проверки выполнены локально без скачивания SDK, Gradle и сетевых зависимостей. **APK не собирался, приложение на Android-устройстве и вывод AudioTrack не тестировались.**

| Проверка | Результат |
| --- | --- |
| Музыкальная теория, генерация и настоящий экспорт MIDI | 6 групп, 17 263 успешных утверждения |
| Хранилище и JSON резервных копий | 11 сценариев, 352 успешных утверждения |
| Синтезатор и реальные PCM-данные | 285 успешных утверждений |
| Синтаксис Java 17 | Все 18 Java-файлов разобраны без ошибок |
| Согласованность типов приложения | Все 9 Java-файлов приложения совместно компилируются с минимальными проверочными заглушками Android |
| XML manifest и ресурсов | Разбор без ошибок |
| `gradlew` | Синтаксис shell без ошибок |
| Собственный загрузчик Gradle | Байткод Java 17; запуск без сети; локальная загрузка/распаковка, кэш, аргументы с пробелами, код завершения и отклонение небезопасных путей ZIP проверены |

Проверка MIDI разбирает настоящий результат `MidiWriter.export`: дорожки, темп, длительности, порядок событий и завершение нот. Проверка хранилища использует производственный JSON-код и модель с небольшими in-memory заменами Context/SharedPreferences; она не проверяет запись на диск Android. Проверка синтезатора анализирует реальные PCM-сэмплы, высоты, уровни и длительность; звук через телефон не проверялся.

Включены результаты стартового проекта: `starter-idea.mid` (SMF type 1, 4 дорожки, PPQ 480) и `starter-idea.wav` (44,1 кГц, mono PCM 16 bit, около 7 секунд). Файлы созданы настоящими `MidiWriter` и `SynthCore`; структура MIDI и WAV проверена отдельно.

Заглушки для совместной компиляции находятся только в отдельной временной папке и не включены в приложение. Они помогают проверить внутренние типы, конструкторы и обработчики, **но не заменяют настоящий Android SDK и не подтверждают успешную Android-сборку**.

Команды из корня проекта с полным JDK 17/21:

```sh
java tools/RunEngineTests.java
java tools/RunStoreTests.java
java tools/RunSynthTests.java
java tools/CheckJavaSyntax.java
```

Проверка загрузчика без сети:

```sh
./gradlew --wrapper-info
```

Настоящая сборка с Android SDK на своём компьютере:

```sh
./gradlew assembleDebug
```

На Windows используй `gradlew.bat`. APK должен появиться в `app/build/outputs/apk/debug/app-debug.apk`; нужны SDK Platform 35, Build-Tools 35.0.0 и интернет при первой синхронизации.

Поведение интерфейса, звук и аудиофокус, сохранение на телефоне, системный выбор документов, импорт в FL Studio и переход в Google остаются проверками на устройстве. Список действий — в [BUILD.md](BUILD.md).
